# 🎯 Guessing Number Game

A simple **Guessing Number Game** built using HTML and JavaScript. The computer generates a random number, and the user has to guess the correct number with the help of hints.

## 📌 Features

- Generates a random number within the maximum range entered by the user.
- Allows the user to guess the number.
- Provides hints if the guessed number is too small or too large.
- Displays a success message when the correct number is guessed.
- Allows the user to quit the game by entering `quit`.
- Uses JavaScript `prompt()` and `console.log()` for user interaction and output.

## 🛠️ Technologies Used

- HTML5
- JavaScript

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter the maximum number when prompted.
5. Guess the random number using the hints provided.
6. Type `quit` to exit the game.
